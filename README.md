A beginner-friendly, modular deep learning project built in Python and TensorFlow/Keras to demonstrate how Convolutional Neural Networks (CNNs) and Transfer Learning can be applied to classify chest X-ray images (e.g., Normal vs. Pneumonia).

## ⚡ Quick Start (Windows 10/11 PowerShell)

### 1. Set Up Environment
Open PowerShell in this directory:
```powershell
# Set process execution policy if needed
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# Create and activate virtual environment
python -m venv venv
.\venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### 2. Prepare the Public Dataset
Download a public, anonymized chest X-ray dataset such as the [Kaggle Chest X-Ray (Pneumonia) Dataset](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia) (licensed under CC BY 4.0).

Place the images in `data/raw/` in either of the supported formats:
* **Split format**: `data/raw/train/{NORMAL, PNEUMONIA}`, `data/raw/test/`, `data/raw/val/`
* **Unified format**: `data/raw/{NORMAL, PNEUMONIA}`

Check readiness:
```powershell
python main.py check-data
```

### 3. Train the Model
```powershell
# Train the transparent Custom Baseline CNN
python main.py train --epochs 15 --batch-size 32

# Or train using Transfer Learning with MobileNetV2
python main.py train --model-type mobilenetv2 --epochs 10
```

### 4. Run Single-Image Prediction
```powershell
python main.py predict --image "data/raw/test/PNEUMONIA/sample_image.jpeg"
```

## 📊 Outputs & Artifacts

All experiment artifacts are automatically saved upon training:
1. **`models/best_model.keras`**: Highest validation-performance model weights.
2. **`models/class_names.json`**: Exact mapping of class names.
3. **`outputs/training_curves.png`**: Multi-panel plot showing loss, accuracy, and AUC over epochs.
4. **`outputs/confusion_matrix.png`**: Annotated heatmap showing True Positives, False Positives, True Negatives, and False Negatives.
5. **`outputs/training_summary.json`**: Detailed JSON record of training parameters and evaluation metrics.
6. **`outputs/prediction_result.png`**: Visual comparison card displaying the query image and prediction confidence bars.

## 🔬 Limitations & Responsible AI

* **Confounding Variables**: Deep models can fixate on hospital radiopaque markers, scanner artifacts, or patient rotation rather than clinical pathology.
* **Class Imbalance**: Imbalanced training data can cause higher false-negative rates for rarer conditions.
* **Domain Adaptation**: Models trained on images from one clinical center may degrade significantly when tested on images from another center.
* Detailed analysis is provided in [EXECUTION_GUIDE.md](file:///c:/Users/Aniksha/OneDrive/Desktop/IIP%20PROJECTS/AI-Powered%20Medical%20Image%20Analysis/docs/EXECUTION_GUIDE.md).
